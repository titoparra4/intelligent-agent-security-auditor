# Sample reports

Generated by the CLI from the examples in this repository (static mode, no network).
`tests/unit/test_docs.py::test_sample_reports_match_current_output` fails when the implementation
changes the findings without the samples being refreshed.

| File | Command |
|---|---|
| `vulnerable-agent-lab.{md,json,sarif,html}` | `agent-security-auditor audit examples/vulnerable-agent-lab --assessment-id ASSESSMENT-EXAMPLE --target-name enterprise-assistant-demo --format markdown,json,sarif,html -o examples/sample-reports --basename vulnerable-agent-lab` |
| `secure-agent.{md,json}` | `agent-security-auditor audit examples/secure-agent --assessment-id ASSESSMENT-SECURE-EXAMPLE --target-name enterprise-assistant-secure --format markdown,json -o examples/sample-reports --basename secure-agent` |
| `secure-agent-enterprise-policy.md` | same with `--policy examples/policies/enterprise-secure-agent.yaml --assessment-id ASSESSMENT-SECURE-ENTERPRISE --basename secure-agent-enterprise-policy` (READY_WITH_RISKS) |
| `compare-secure-vs-lab.json` | `agent-security-auditor compare examples/sample-reports/secure-agent.json examples/sample-reports/vulnerable-agent-lab.json --format json` |

Regenerate all with `python skills/intelligent-agent-security-auditor/scripts/generate_report.py ...` or the commands above. Timestamps differ
between runs; finding ids, evidence and verdicts are deterministic.
